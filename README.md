# Привет! Я Данил 👋

Начинающий Python Backend Developer.

Разрабатываю асинхронные backend-приложения и Telegram-ботов. Работаю с REST API, базами данных, авторизацией, тестированием и контейнеризацией приложений.

## Технологии

- Python, FastAPI, aiogram
- SQLAlchemy, PostgreSQL, SQLite, Alembic
- REST API, JWT, access и refresh-токены
- asyncio, Redis
- pytest, Ruff
- Docker, Git, GitHub Actions

## Основные проекты

### [NoteKeeper API](https://github.com/Danil1713/NoteKeeper-API)

Асинхронный REST API для управления заметками.

- регистрация и аутентификация пользователей;
- JWT access и refresh-токены;
- CRUD, поиск, сортировка и пагинация;
- SQLAlchemy и Alembic;
- автоматические тесты и CI;
- запуск приложения в Docker.

### [Python Practice Bot](https://github.com/Danil1713/Python-Practice-Bot)

Telegram-платформа для изучения Python через практические проекты.

- асинхронный Telegram-бот на aiogram;
- PostgreSQL, SQLAlchemy и Alembic;
- проверка решений с использованием AI;
- система подписок и Telegram Stars;
- Redis и Docker.

## Обо мне

- обучаюсь по программе «Python-разработчик» в Нетологии;
- развиваюсь в направлении backend-разработки;
- открыт к предложениям на позицию Junior Python Developer.
